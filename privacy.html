개인정보처리방침

스마트 홈 대시보드 · 시행일 2026년 10월 26일

스마트 홈 대시보드(이하 "대시보드")는 사용자의 라즈베리파이에서 실행되는 개인용 프로그램입니다. 개발자는 별도의 서버를 운영하지 않으며, 사용자의 정보를 수집해 보관하지 않습니다.

1. 이용하는 정보

  • Google 계정 이메일 주소: 어느 계정이 연결되었는지 설정 화면에 표시하기 위해 사용합니다.
  • Google 캘린더 일정 (기본 캘린더의 오늘·내일 일정 제목과 시간): 대시보드 화면과 아침 브리핑에 보여 주기 위해 읽습니다.
  • 일정 추가·삭제: 사용자가 말로 요청하고 소리 또는 버튼으로 한 번 더 확인한 경우에만 기본 캘린더에 일정을 추가하거나 지웁니다. 지울 일정을 찾기 위해 해당 날짜(또는 앞으로 두 달)의 일정 제목을 읽습니다.
  • 태블릿의 위치(좌표): 현재 위치의 날씨를 가져오기 위해 사용합니다.
  • 음성 질문 내용: 질문에 답하기 위해 사용합니다. 일정 추가 요청의 날짜·시간 해석은 외부로 보내지 않고 라즈베리파이 안에서 처리합니다.

2. 저장 위치

  • Google 로그인 정보(갱신 토큰)는 사용자의 라즈베리파이 안의 파일에만 저장됩니다.
  • 일정 길이·알림 같은 대시보드 설정은 라즈베리파이 안의 파일에 저장됩니다.
  • "방금 넣은 일정 지워 줘", "되돌려 줘" 같은 요청을 처리하기 위해, 대시보드에서 말로 넣거나 지운 일정의 제목·날짜·시간을 최근 10개까지 라즈베리파이 안의 파일에 기록합니다. 지운 일정은 되돌릴 수 있도록 내용(제목, 시간, 장소, 메모, 알림)을 함께 기록합니다.
  • 캘린더에서 읽어 온 일정 목록은 같은 내용을 반복해서 요청하지 않도록 프로그램 실행 중 최대 5분 동안만 메모리에 보관합니다.
  • 오늘 일정이 들어간 아침 브리핑 문장은 하루에 한 번만 만들도록 라즈베리파이 안의 파일에 저장되며, 다음 날 또는 연결 해제 시 삭제됩니다.
  • 위치 좌표와 화면 설정은 태블릿 브라우저 안에만 저장됩니다.

3. 외부 서비스로 보내는 정보

  • 기상청 공공데이터 API: 날씨 조회를 위해 위치를 변환한 격자 좌표를 보냅니다.
  • Google Gemini API: 브리핑과 답변 문장을 만들기 위해 날씨 정보, 질문 내용, 오늘·내일 일정의 제목과 시간을 보냅니다.
  • Google 음성 인식: 태블릿의 크롬 브라우저 음성 인식 기능을 사용하며, 이 처리는 브라우저가 담당합니다.

위 목적 외에 정보를 판매하거나, 광고에 사용하거나, 다른 제3자에게 제공하지 않습니다.

4. Google 사용자 데이터 정책 준수

대시보드가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 것은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

5. 연결 해제와 삭제

  • 대시보드의 설정 → 구글 캘린더 → 연결 해제를 누르면 Google에 권한 취소를 요청하고, 라즈베리파이에 저장된 로그인 정보, 일정이 들어간 브리핑, 최근 기록을 삭제합니다.
  • Google 계정의 서드 파티 액세스 관리 페이지에서도 언제든지 권한을 취소할 수 있습니다.
